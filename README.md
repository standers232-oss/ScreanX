# ScreanX

Современный инструмент для создания скриншотов, аннотаций и записи видео с экрана Windows в стиле Google Material Design 3.

## ✨ Возможности

- **Захват экрана**: произвольная область, весь экран, активное окно, таймер 3 секунды.
- **Улучшение качества**: алгоритм 2x Super-Resolution для четкости мелких областей и текста.
- **Инструменты аннотаций**: стрелки, прямоугольники, окружности, карандаш, маркер, нумерованные шаги (1, 2, 3...), размытие/цензура, текст.
- **Запись видео**: форматы MP4, AVI и GIF с реальной скоростью 1:1, записью курсора и автоматическим скрытием панели управления из кадра (WDA).
- **Экранные утилиты**: пипетка цвета (HEX/RGB), линейка размеров, закрепление картинки поверх окон (Pin).
- **Material 3 UI**: 4 цветовые палитры (Purple, Teal, Blue, Orange), темная и светлая темы, плавный инерционный скролл, системный трей, единый процесс (Single-Instance).

## 🚀 Сборка проекта

Требования: .NET 8.0 SDK (Windows).

```bash
# Сборка проекта
dotnet build

# Публикация релиза
dotnet publish -c Release -o ./publish
```
